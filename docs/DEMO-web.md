# Web 实时台 · 可演示版本(演示剧本)

> 对应 ADR-0012(ADR-0008 Web 实时台的首个可演示交付)。
> 全程零硬件、零浏览器插件:打开一个网址,按下面 5 分钟剧本走。
> 模拟源时基为 sw/L0(ADR-5 分级承诺),UI 徽章如实标注。

## 启动

```bash
# 开发运行(首次需编译)
cargo run --release -p iotprobe-web
# 或直接用已构建产物
target\release\iotprobe-web.exe            # 默认 127.0.0.1:8791
target\release\iotprobe-web.exe --port 8791 --bind 0.0.0.0   # 手机/同事局域网访问
```

浏览器打开 `http://127.0.0.1:8791`。

## 5 分钟剧本(对齐 G2 S1 的离线叙事)

| 分钟 | 动作 | 预期画面 | 背后的能力 |
|---|---|---|---|
| 0–1 | 打开页面,什么都不动 | 报文流以 ~110 帧/s 滚动(MOTOR_STATUS@10ms、HEARTBEAT@500ms、FD_CALIB@2s);曲线三条正弦平稳;聚合表周期抖动 <5%;事件区安静 | NDJSON 契约管线 + DBC 解码 + Canvas 抽稀 |
| 1–2 | 点 **「注入温度故障」**(保持按下的状态) | Temp 曲线 1.5s 内爬到 ~64 °C;事件区先出 **MOTOR_TEMP_WARN**(橙),随后 **MOTOR_TEMP_FAULT**(红,带证据信号值);点事件 → 报文表跳到对应帧并高亮 | YAML 规则包(阈值+for 持续时长)+ 事件证据链 + 三联动 |
| 2–3 | 再点一次按钮(**停止故障**) | Temp 骤降;**MOTOR_TEMP_DROP**(橙,rate=xx °C/s)出现在事件区 | 变化率规则(滑动窗口 Δ值/Δ秒,ADR-6) |
| 3–4 | 点 **「心跳停发 3s」** | 聚合表 HEARTBEAT 一行变黄(抖动 σ% 飙升);事件区出现 **DIAG_TIMING_GAP**(warn)诊断事件;报文表可见 0x100 缺段 | 丢帧/断流检测(诊断事件,builtin-diag 证据链) |
| 4–5 | 过滤栏输入 `0x1A0, 0x100` → 应用;再看 `/api/stats` | 报文表只剩这两个 ID(注意:**过滤在服务端做**,带宽不灌给浏览器);`/api/stats` 显示帧/信号点/事件计数与会话时长 | T-1.11 服务端过滤器 |

## 给 AI 看(S3 味道的延伸)

- `GET /api/stats` 返回会话计数(帧/信号点/事件/运行时长)。
- 每条事件都带 `evidence{signals, frames_ref, rule_ref}`(event.schema),复制给任意 AI 都能回答"发生了什么、证据是哪一帧、规则出处是哪一行"。
- 与 MCP server(`mcp_server.exe`)共用同一套契约导出:GUI/CLI 侧 `--export` 的 JSONL 即 MCP 数据源(见 README S3 节)。

## 已知边界(诚实声明)

- 客户端**加入后曲线只向前填充**(60s 窗口逐步填满),不做历史回放;回放能力在 egui 台/CLI。
- 会话为全量累积以稳定规则语义(ADR-0012),软上限 15 万条记录(约 20 分钟),超限摄入自动停止——长时间演示请重启会话。
- 模拟源时基 sw/L0;跨总线 <1µs 对齐(L2)只有 PH-4 网关硬件能承诺。
- WS 无鉴权,默认只绑 127.0.0.1;`--bind 0.0.0.0` 仅限可信局域网演示。
- 过滤器作用于 frame 类消息;事件/信号始终全量(避免客户端错过证据链)。
