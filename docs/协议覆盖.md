# 协议覆盖矩阵

> 各协议的解析能力清单。所有协议都要求**真实样本验证**(纪律见 roadmap J5 红线 4);
> 未取得真实样本的协议在"待真实样本"区,不宣布生产可用。

## 已验证(真实样本)

| 协议 | 样本来源 | 覆盖能力 |
|---|---|---|
| Modbus RTU/ASCII/TCP | 自产样本+真实抓包 | 全功能码读写、事务配对、RTT |
| IEC 60870-5-104(标准) | Wireshark wiki(真实变电站) | APCI/总召/遥测/遥控/遥信/时序;OA 裁决后 IOA 真值 |
| **DL/T 645-2007** | ⏳ **合成帧先行,真表 golden 采购中**(485 导轨表) | 帧定界(CS 自纠)/读数据 0x11/DI 常用项/出错响应/FE 唤醒/失步重扫 |
| S7comm | Wireshark wiki(真实 S7-300) | TPKT/COTP/ROSCTR/Setup/Read/Write Var 变量项/事务配对 |
| EtherCAT | Wireshark wiki(Beckhoff) | 报文+WKC |
| DNP3 | Wireshark wiki(ICS-pcap 多站) | 链路帧+CRC 验证 |
| MQTT | pradeesi 真实抓包 | CONNECT/PUB/SUB 全类型 |
| CAN/CAN FD + DBC | 真表+J1939 TP.BAM | 全解码+多帧重组 |
| CANopen | 合成帧(等协作机器人样本) | NMT/EMCY/SDO 配对/心跳/PDO |
| PROFINET DCP | Wireshark wiki(ChangeIP 流程) | Get/Set 块解码+改 IP 事件;RT 等 GSDML |

## 明确不做

| 协议/能力 | 理由 |
|---|---|
| DL/T 698 / 南网上行下行 / Q/GDW 376.2 / IEC 62056-21 | 国网营销业务客户群,与储能/工控不重叠;标准文本收费 |
| PROFIBUS DP | RS485 串口形态,无以太网 pcap 样本;需串口采集硬件 |
| 纵向加密装置密文隧道 | 厂商私有格式+密钥在装置内 |
| HIL 故障注入 / CAN restbus 仿真 / 协议模糊测试 | 三条否决线(CANoe/TSMaster 主场) |
