# ADR-0015 配置中心场景化（场景视图 + 步骤化操作 + 快捷键）

状态：已采纳（2026-11-20）　关联：ADR-0013（配置中心）/ G2-acceptance（S1/S2/S3）

## 背景

配置中心整页（ADR-0013）把 7 张卡一次全铺开——功能都可见,但与"当前任务"无关的设置也在
视野里;G2 验收清单的三个场景（S1 现场排故 / S2 产线抽测 / S3 数据喂 AI）是真实使用主线,
每个场景实际只需要其中 3~4 张卡,且存在天然先后顺序（连硬件 → 挂协议 → 挂规则 → 留证）。

## 决策

1. **场景视图**：配置中心顶部常驻场景条,六个入口（快捷键 1~6）——
   `1 离线分析 / 2 现场排故 / 3 产线抽测 / 4 数据喂AI / 5 模拟联调 / 6 全部配置`。
   每个场景**只渲染该任务需要的卡片模块**,场景对齐 G2 验收场景。
2. **步骤化**：场景内容按步骤排布（`step_card`:编号 + 标题 + 完成徽章 + 主体）。
   完成徽章由状态推导（连了实时→✓、挂了协议→✓、解锁发送→✓…）,不存持久状态,无并发真值问题。
3. **模块复用**：场景步骤体直接复用 ADR-0013 的卡片模块（card_live/card_protocol/card_rules/…）,
   零逻辑复制——同一张卡在任何场景出现,状态与操作同源;新卡片实现一次即可挂进任意场景。
4. **快捷键**（无文本框聚焦时生效;F1 帮助窗列出全部）：
   - 配置中心页:数字 `1~6` 切场景
   - 全局:`Ctrl+1~6` 直达场景（自动切到配置中心）、`Ctrl+0` 回工作台、`F1` 帮助
   - 工作台原有键（Space/F/+−/←→）限定工作台页生效
5. **S3 场景内嵌 MCP 注册**：`ai-setup` 配置片段按当前 exe 路径生成展示 + 一键打开
   `MCP使用教程.md`（教程随发布包分发,见 package_release.py）。
6. **持久化**：`scene` 随 iotprobe_session.json 记忆（重启回到上次场景）。

## 后果

- "每次只显示与当前任务相关的设置"落地:现场排故场景看不到模拟器卡,数据喂AI 场景只有三步。
- 步骤化顺序与 G2 手跑清单一致——UI 操作顺序即验收步骤,新人按步骤条就能走完场景。
- `step_card`/`config_card` 都是关联函数（无 self 接收者）——调用点闭包独占捕获 &mut self,
  与方法接收者借用冲突（egui 闭包标准约束,与 tool_windows 同款处理）。
- 快捷键 `1~6` 在配置中心页直接生效,文本框聚焦自动失效;工作台键不再泄漏到配置页。

## 修订(2026-11-23,I12)

- **场景合并**:产线抽测并入现场排故(两场景卡片高度重叠),六入口→
  `1 离线分析 / 2 现场排故(含产线抽测) / 3 数据喂AI / 4 模拟联调 / 5 全部配置`;快捷键 1~5(原 1~6)。
- **使用引导窗落地**(决策当时未接线):首启(无数据无 samples)弹「这次做什么」任务选择页 →
  每屏一步(上一步/下一步/完成→自动切场景),菜单「分析工具→使用引导」重进;会话恢复直接回上次任务步骤。
- S2 产线抽测剧本仍按 G2 手跑:并入现场排故后由步骤 4「发送激励(可选)」覆盖抽测路径,验收步骤不减。

## 修订(2026-11-24,I14 向导重构)

- **引导不再是浮窗,是主页面**:I12 的引导窗(guide_window)与"每屏一卡"的步骤视图合并为一个 `wizard_screen`——
  向导模式下配置中心直接渲染当前步:问句标题 → 只露必填子块 → 就地结果(✓/○ 由状态推导)→ 门控的下一步。
  删除 `guide_window`/`guide_render_step`/`show_guide`;菜单「使用引导」与首启都落到任务选择页。
- **任务选择页按用户处境措辞**(有日志/设备在手边/没设备想模拟/让 AI 看/我是熟手),场景名退为角标;顶部任务卡行与快捷键 1~5 保留给熟手。
- **门控只卡真需要结果的步**(打开文件/连硬件/起模拟器),其余显式标"可选";「完成」有落点:工作台,模拟联调同时打开点位编辑。
- **卡片分块是向导与专家视图的共同底座**:`live_form_parts` 位掩码、`card_data_source_parts`;向导只拼块,不复制卡片逻辑;
  `scene_steps`(按任务平铺卡片)保留为非向导视图——"熟手可跳过"有实路径,不是口头承诺。
- 后果:后续新增配置项时,先问"它属于哪一步、是不是必填",再加到对应分块;不要往向导屏塞整张卡。
